# CHANGELOG / История изменений проекта

Все изменения, обновления архитектуры и функционала веб-приложения **«УТТиСТ Подменный Водитель»** (Справочник и оперативный блокнот подменного водителя УТТиСТ ООО «Газпром добыча Ямбург») с детальной пошаговой версификацией.

---

## [1.5.4] — 2026-10-05
### Добавлено
- **Прямая ссылка и кнопка «Поделиться» карточкой ТС**:
  - На карточке выбранного автомобиля добавлена кнопка **«Поделиться»** (иконка `Share2`).
  - Генерация уникальной прямой ссылки на автомобиль по его гаражному номеру (например, `/#1129`).
  - Поддержка нативного меню шаринга мобильных устройств (`navigator.share`) для моментальной отправки в Telegram, WhatsApp, SMS или VK.
  - Автоматический fallback: копирование ссылки в буфер обмена (`navigator.clipboard`) с наглядной анимацией «Ссылка скопирована! Отправьте её водителю».
  - Автоматическое открытие карточки при переходе по ссылке:
    - При открытии адреса вида `/#1129` (или `?g=1129`) приложение мгновенно находит автомобиль в базе и сразу разворачивает его карточку без необходимости ручного ввода в поле поиска.
    - Синхронизация хэша в адресной строке браузера при выборе ТС и очистка хэша при возврате ко всему списку.

---

## [1.5.3] — 2026-10-05
### Исправлено и Улучшено
- **Сброс поля поиска при нажатии «Показать список всех автомобилей»**:
  - Устранена проблема, при которой после поиска по гаражному номеру нажатие на кнопку «Показать список всех автомобилей» продолжало удерживать фильтр поиска и отображало только одну карточку найденного ТС.
  - Теперь при нажатии на «Показать список всех автомобилей»:
    1. Поле поиска немедленно очищается от введённого ранее гаражного номера;
    2. Сбрасывается выбор отдельного автомобиля;
    3. Сбрасываются ограничивающие фильтры по автоколоннам и сменам;
    4. Моментально открывается полный каталог всей техники автопарка.

## [1.5.1] — 2026-10-01
### Изменено
- **Реорганизация кнопок добавления контактов и очистка интерфейса**:
  - На главной карточке автомобиля в блоке «Заказчик и Подача» полностью убраны кнопки добавления контакта — карточка оставлена исключительно для быстрого считывания информации и звонков в один клик.

  - Удалены дублирующие кнопки под полями ввода контактов заказчика и водителей для компактности формы на экранах смартфонов.

  - Глобальный поиск теперь находит автомобили по ФИО и телефонам любых контактов заказчика.

## [1.0.0] — 2026-09-20
### Релиз: Первоначальное основание проекта
- Запуск приложения «УТТиСТ Подменный Водитель» на базе React 19, TypeScript, Vite, Tailwind CSS и Firebase Firestore.
